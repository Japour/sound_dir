### Added
- Initial public release
- WASAPI loopback audio capture
- PCEN-based per-bin direction estimation across 4 frequency bands
- Transparent always-on-top overlay with `egui` + `wgpu`
- System tray icon with menu (edit, reset, quit)
- Edit mode with drag-to-move, corner-handle resize, settings panel
- Persistent settings in `%APPDATA%/sound_dir/settings.json`
- Custom embedded `.exe` icon generated at build time
- Comprehensive architecture documentation
